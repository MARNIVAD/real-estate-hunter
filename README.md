# AI Real Estate Bot Da Nang — MVP

## Что это

Telegram-бот для риелторов в Дананге. Клиент приходит по персональной ссылке
риелтора, описывает желаемую квартиру свободным текстом (русский, английский,
вьетнамский), а бот:

1. извлекает параметры запроса через OpenAI (`gpt-4o-mini`);
2. задаёт уточняющие вопросы, пока не собраны критичные слоты (комнаты и бюджет);
3. ищет подходящие активные листинги риелтора в PostgreSQL;
4. при отсутствии точных совпадений постепенно ослабляет фильтры;
5. отправляет клиенту фото, описание и цену вариантов;
6. создаёт лид и присылает риелтору уведомление с переводом запроса на русский.

Риелтор управляет листингами и смотрит лиды прямо в боте.

Стек: Python 3.11+, aiogram 3.7+, SQLAlchemy 2.0 (async), Alembic, PostgreSQL
(asyncpg), OpenAI API, pydantic-settings. Подготовлено для запуска на Render.

## Установка (5 минут)

### 1. Требования

- Python 3.11+
- PostgreSQL 14+ (локально или облачный, например Render Postgres)
- Токен бота от [@BotFather](https://t.me/BotFather)
- (Опционально) ключ OpenAI API

### 2. Клонирование и зависимости

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Переменные окружения

```bash
cp .env.example .env
```

Заполните `.env`:

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | да | Токен Telegram-бота |
| `DATABASE_URL` | да | Строка подключения PostgreSQL |
| `OPENAI_API_KEY` | нет | Без ключа бот работает в mock-режиме |
| `ADMIN_TELEGRAM_ID` | нет | Зарезервировано для админских функций |
| `OPENAI_MODEL` | нет | По умолчанию `gpt-4o-mini` |
| `USD_VND_RATE` | нет | Курс для сравнения цен, по умолчанию `25000` |

`DATABASE_URL` можно указывать в формате `postgresql://...`, `postgres://...` или
`postgresql+asyncpg://...` — приложение само приведёт её к asyncpg.

Важно: файл `.env` не коммитится. В репозитории есть только `.env.example`.

### 4. Создание базы данных

Если PostgreSQL локальный:

```bash
createdb danang_bot
```

Либо создайте базу в панели Render и возьмите оттуда External Database URL.

## Запуск миграций

```bash
alembic upgrade head
```

Проверить текущую версию:

```bash
alembic current
```

Откатить все миграции (осторожно, удалит данные):

```bash
alembic downgrade base
```

```bash
python run.py
```

При отсутствии `BOT_TOKEN` бот завершится с понятной ошибкой в логе.

## Как пользоваться

### Риелтор

1. Напишите боту `/agent_start` и пройдите регистрацию (имя, телефон).
2. `/add_listing` — пошаговое добавление листинга:
   - фото (можно несколько, затем `/done`; `/skip` — без фото);
   - количество комнат (`0` — студия);
   - цена и валюта (например `1200 USD` или `30000000 VND`);
   - район;
   - можно ли с питомцами;
   - описание (или `/skip`);
   - подтверждение.
3. `/my_listings` — список листингов с кнопками деактивации и удаления.
4. `/my_leads` — последние 10 лидов со статусами.
5. `/cancel` — отменить текущее действие.

После регистрации риелтор получает свой `agent_<id>`. Ссылка для клиентов:

```text
https://t.me/<bot_username>?start=agent_<id>
```

### Клиент

1. Переходит по ссылке риелтора.
2. Пишет запрос в свободной форме, например:
   `Ищу 2-комнатную квартиру до 1500 USD в районе My Khe, можно с собакой`.
3. Отвечает на уточняющие вопросы.
4. Получает подборку и подтверждение, что лид передан риелтору.

## Импорт листингов из Excel

Риелтор запускает импорт командой `/import_excel` в боте. Бот просит прислать
файл `.xlsx`, затем создаёт листинги в БД и записывает статус в `import_jobs`,
ошибки по строкам — в `import_errors`.

### Формат Excel-файла

Обязательные колонки (заголовки в первой строке, регистр не важен):

| Колонка | Описание | Обязательная |
|---|---|---|
| `title` | Название / описание листинга | да |
| `rooms` | Количество комнат (0 — студия) | нет |
| `price` | Цена | да |
| `currency` | Валюта: `USD` или `VND` | нет (по умолчанию `USD`) |
| `district` | Район | нет |
| `pets_allowed` | `да` / `нет` / `1` / `0` | нет |
| `photo_urls` | Ссылки на фото, разделённые запятой или пробелом | нет |

### Логика работы

1. Файл скачивается через Telegram `getFile` / `downloadFile`.
2. Строки без `title` и `price` попадают в `import_errors` с номером строки.
3. Для каждой строки создаётся запись в `listings`.
4. Если указаны `photo_urls` — каждая ссылка скачивается через `httpx`, проверяется,
   что это изображение, и загружается в Telegram (`sendPhoto` → `file_id`).
   Неудачные ссылки — с записью ошибки в `import_errors`, импорт продолжается.
5. После завершения бот отправляет отчёт: «Успешно добавлено: X листингов. Ошибок: Y.»

### Пример формирования

Создайте `.xlsx` в Excel / Google Sheets / openpyxl с заголовками из таблицы выше.
Для каждой строки — одна квартира.

### Тестовый файл

Чтобы сгенерировать тестовый файл, запустите `python generate_test_excel.py`.

```bash

    result = await extract_slots("2 комнаты до 1200 USD в районе My Khe, можно с собакой")
```

Проверка поиска и fallback выполняется на реальных данных после добавления
листингов через бота. Автотесты в MVP не включены.

## Деплой на Render (кратко)

1. Создайте Web Service (или Background Worker) из репозитория.
2. Build Command: `pip install -r requirements.txt`
3. Start Command: `python run.py`
4. Добавьте переменные окружения `BOT_TOKEN`, `DATABASE_URL`, `OPENAI_API_KEY`.
5. Для миграций используйте Render Shell: `alembic upgrade head`.
6. Для длительного polling удобнее Background Worker; при использовании Web
   Service health check не требуется.

## Известные ограничения

- FSM-состояния хранятся в памяти процесса (`MemoryStorage`). После рестарта
  незавершённые диалоги сбрасываются; история диалогов при этом пишется в `dialogs`.
- Курс USD/VND фиксированный (`USD_VND_RATE`). Для продакшена нужен живой источник
  курса или нормализованная цена в USD у листинга.
- Импорт листингов из файлов не реализован: таблицы `import_jobs` и
  `import_errors` созданы под будущую функцию.
- Фото хранятся как Telegram `file_id`, отдельного файлового хранилища нет.
- Нет ограничения частоты запросов и антиспама.
- Нет автоматической смены статуса лида из бота (статусы читаются в `/my_leads`).
- Без `OPENAI_API_KEY` извлечение слотов работает по эвристикам, перевод не выполняется.
- Уведомление риелтору не отправляется, если у риелтора не начат диалог с ботом
  (Telegram не позволяет писать первым).
- Кнопка «Связаться с клиентом» использует `username`; если его нет, показывается
  Telegram ID и ссылка `tg://user?id=...`.

## Структура проекта

```text
app/
  config.py              # настройки из .env
  db.py                  # async engine и session factory
  models.py              # SQLAlchemy 2.0 модели
  bot/
    main.py              # точка входа aiogram
    handlers/client.py   # клиентский слот-филлинг и поиск
    handlers/agent.py    # регистрация и CRUD листингов
    keyboards.py
    states.py
  services/
    llm.py               # извлечение слотов и перевод
    search.py            # поиск и fallback
    notifier.py          # уведомление риелтора
alembic/                 # миграции
alembic.ini
run.py
```
